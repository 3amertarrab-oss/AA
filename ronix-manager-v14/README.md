# RONIX V19

**[تحميل النسخة الجاهزة V19](https://github.com/3amertarrab-oss/AA/raw/refs/heads/ronix-finance-download/ronix-manager-v14/RONIX-V19.zip)**

نُفذت البنود الثلاثة: تحديث سعر الصرف بزر مع الإدخال اليدوي، أرقام مستندات قصيرة، وإخفاء القروش من العرض.

- **سعر اليوم:** في سند القبض أو المشروع الجديد اختر العملة واضغط «تحديث سعر اليوم». يظهر السعر المنشور وتاريخه، ويظل الحقل قابلًا لكتابة سعر البنك. المصدر [Currency API](https://github.com/fawazahmed0/exchange-api) مجاني دون مفتاح أو اشتراك حاليًا، ويتحدث يوميًا؛ السعر مرجعي وليس سعر شراء أو بيع بنك معين. لا يجلب البرنامج السعر إلا عند الضغط، ولا يرسل بيانات العملاء أو المبالغ.
- **الحفظ:** يُحفظ السعر ومصدره وتاريخه عند حفظ الحركة. التعديل اليدوي يُسجل كإدخال يدوي. إذا تعذر الاتصال يبقى السعر السابق. يمنع التحديث المتأخر من الكتابة فوق تعديل يدوي أو عملة أخرى، وسعر التعاقد التاريخي ثابت بعد وجود مطالبات أو تحصيلات.
- **رقم المستند:** مثل `CL-0001` للمطالبة و`RC-0001` للقبض و`PV-0001` لدفعة المصمم و`AD-0001` للمقدمة. يظهر في الشاشات والكشوف والطباعة والتصدير. تبقى المعرفات الداخلية والمطابقات والمرفقات ومراجع البنك كما هي؛ الرقم القصير مستقل عنها، محفوظ في JSON، ولا يعاد استخدامه عند حذف حركة.
- **دون قروش:** تُعرض المبالغ لأقرب وحدة، مثل `388,361.97` ← `388,362`. القيم المخزنة والحسابات والمدخلات وبيانات Excel الرقمية تبقى دقيقة؛ تنسيق خلايا المبالغ فقط دون كسور. سعر الصرف يبقى حتى ست منازل. قد يختلف جمع القيم المعروضة عن تقريب مجموعها بسبب التقريب؛ لا تُنشأ تسوية مالية لإخفاء هذا الفرق.

**لنقل بياناتك:** صدّر أحدث JSON من النسخة التي تعمل عليها الآن، سواء V17 أو V18. فك ضغط V19 وافتح `RONIX_Manager.html` ثم «التقارير ← استعادة نسخة». راجع أرصدتك ثم نزّل نسخة V19 جديدة.

## تحديث العملاء السابق V18

أضيفت قائمة مستقلة للعملاء، وحقل اختيار قابل للبحث والكتابة في نموذج المشروع. **اكتمل طلب العملاء السابق: 3 من 3 بنود.**

**[النسخة السابقة V18](https://github.com/3amertarrab-oss/AA/raw/refs/heads/ronix-finance-download/ronix-manager-v14/RONIX-V18.zip)**

- **اختيار عميل موجود:** اضغط سهم حقل اسم العميل، أو اكتب جزءًا من اسمه للبحث، ثم اختره.
- **كتابة عميل جديد:** اكتب الاسم واحفظ المشروع؛ يُضاف العميل إلى دليله تلقائيًا مع نجاح حفظ المشروع.
- **قائمة منفصلة:** قسم «العملاء» في القائمة الجانبية للإضافة والتعديل والبحث والهاتف والبريد والملاحظات، مع فتح كشف الحساب أو إنشاء مشروع أو تحصيل.

تظهر أسماء الدليل أيضًا في قوائم التحصيل والمطالبات والمقدمات والأرصدة الافتتاحية. تستطيع تسجيل عميل وتحصيل غير موزع قبل إنشاء مشروع. تُستخرج الأسماء القديمة تلقائيًا دون دمج حسابات موجودة أو تغيير المبالغ. اختلاف المسافات أو حالة الأحرف في اسم جديد يعيد استخدام الاسم الموجود؛ الأسماء القديمة المتشابهة تبقى منفصلة حتى تراجعها بنفسك.

تعديل اسم العميل من دليله يحدّث الاسم في مشاريعه وسنداته ومطالباته ومقدماته وأرصدته الافتتاحية وسجلات المشاريع القابلة للاستعادة في عملية حفظ واحدة. لا يدمج حسابين. تبقى الصور والمرفقات ومعرّفات الحركات وتاريخ التعديلات محفوظة. يوجد معرّف ثابت لسجل العميل، مع استمرار الروابط المالية القديمة باسم العميل. دليل العملاء محفوظ في JSON ومتوفر في Excel مستقل والتصدير الشامل.

**لنقل بياناتك:** من النسخة التي تعمل عليها حاليًا، افتح «التقارير» وصدّر أحدث JSON. فك ضغط V19 وافتح `RONIX_Manager.html`، ثم «التقارير ← استعادة نسخة» واختر ذلك الملف. لا تستخدم نسخة V16 قديمة إذا أضفت حركات بعدها. راجع السجلات ثم صدّر نسخة V19 جديدة. ملفات التنزيل العامة خالية من حساباتك وصورك ومستنداتك.

## المراجعة السابقة V17

نُفذت 6 من 7 ملاحظات (نحو 86%)؛ بند الضريبة ينتظر تحديد نوعها ونسبتها. ربط Google والعمل عبر الأجهزة لم يُنفذ؛ البرنامج ما زال HTML محليًا.

| ملاحظة المراجعة الأخيرة | النتيجة |
|---|---|
| حذف المشروع | حذف قابل للاستعادة للمشروع دون حركات، مع تكليفاته. إذا توجد دفعات أو مطالبات أو مصروفات، تتم الأرشفة مع حفظ الأرصدة. |
| حذف المصمم والتكليف | حذف واستعادة للتكليفات غير المدفوعة؛ الأرشفة تحمي السجلات المرتبطة بالدفعات، بما فيها الدفعات المحذوفة القابلة للاستعادة. |
| نقل النسخ الاحتياطي والاستعادة | داخل صفحة التقارير، مع سلة المحذوفات والأرشيف. |
| التحصيل بالجنيه لعقد بعملة أخرى | إدخال النقد يحسب مقابل العقد؛ زر يخصص باقي السند. مبلغ المقبوض يبقى كما أُدخل، وفرق التقريب يظهر منفصلًا. |
| Excel المشروع | أول ورقة تعرض بيانات المشروع والمجاميع وأسماء المصممين والأتعاب والدفعات والتحصيلات؛ أوراق تفصيلية إضافية محفوظة. |
| إضافة الضريبة | بانتظار تحديد الضريبة المضافة أو المخصومة ونسبتها. لم تتغير القيم الحالية. |
| إغلاق النوافذ | الضغط خارج النافذة وEscape لا يغلقان نموذج الإدخال. يعمل × وإلغاء، ويغلق النموذج بعد الحفظ الناجح. |

في مثال التحصيل المختبر: 6,500 جنيه مقابل عقد بالريال بسعر تعاقد 14 ينتج 464.29 ريال سدادًا و6,500.06 جنيه مقابلًا دفتريًا؛ النقد الفعلي يبقى 6,500 جنيه، ويظهر فرق تقريب −0.06 جنيه. لا يُنشأ قبض بقيمة 6,500.06، ولا تُرفع قيمة السند لتجاوز تحقق التوزيع.

المحذوفات مستبعدة من المجاميع حتى استعادتها. الأرشيف يخفي السجل من دليل العمل الافتراضي ويحافظ على سجلاته في الحسابات والتقارير. تغيير اسم/كود سجل مستخدم قد يمنع الاستعادة إذا تسبب في تكرار؛ البرنامج يتحقق قبل الكتابة. لا توجد إزالة نهائية للصور أو مستندات الحركات المرتبطة.

استورد أحدث JSON الذي تعمل عليه من **التقارير ← استعادة نسخة**. إصدار الحفظ الحالي 19؛ افتح نسخه في V19 أو إصدار أحدث. جميع ملفات التنزيل العامة خالية من حسابات المستخدم وصوره ومستنداته.

الربط الحسابي من V16 محفوظ: الربط التلقائي عند وضوح مطالبة المشروع والعميل؛ الاختيار اليدوي عند تعددها؛ تحديث الأرصدة دون تكرار القبض؛ فصل مستحق المصمم عن دفعاته الزائدة؛ استعادة الصور من ZIP دون استبدال أحدث حساباتك.

افتح `RONIX_Manager.html` بعد فك الضغط. إذا كانت صور JSON تشير إلى مجلد project_media، استخدم «استعادة صور المشاريع» واختر ZIP الأصلي بعد استيراد أحدث JSON، ثم صدّر نسخة جديدة. **صدّر أحدث JSON من النسخة التي تعمل عليها الآن، ثم استورده في V19**؛ لا تستعد ZIP قديمًا إذا أضفت حركات جديدة. البيانات الجديدة تستخدم الإصدار 19 من بنية الحفظ؛ افتح نسخها الاحتياطية بهذا الإصدار أو إصدار أحدث.

## العملات والحسابات

- الجنيه المصري أساس المجاميع والتقارير والمطالبات وأتعاب المصممين والمقدمات. العقود تدعم EGP وUSD وSAR وAED وEUR وGBP وQAR. المبالغ حتى منزلتين عشريتين وأسعار الصرف حتى ست منازل، وتُحفظ مع العملية؛ يمكن إدخال سعر البنك يدويًا أو جلب سعر مرجعي يومي عند الضغط على زر التحديث.
- عقد المشروع = الأصل + التعاقدات الإضافية، بنفس عملة المشروع وسعر تعاقده. سعر التعاقد ثابت بعد وجود مطالبة أو تحصيل؛ سعر كل سند قبض مستقل.
- في سند القبض: «سداد من العقد» بعملة عقد المشروع؛ «مخصص من القبض» بعملة السند. عند تطابق العملتين يتساويان؛ وعند اختلافهما أدخل المبلغ الفعلي المخصص من السند، ويظهر فرق الصرف منفصلًا.
- مثال مختبر: عقد 1,200 USD بسعر 50 = 60,000 ج.م. قبض 400 USD بسعر 51 ثم 800 USD بسعر 52 يسدد العقد بالكامل؛ القبض 62,000 ج.م وفرق الصرف 2,000 ج.م ورصيد العقد صفر.
- المطالبات ومطابقتها تستخدم المقابل الدفتري بالجنيه. أتعاب المصممين والمصروفات والمقدمات تبقى بالجنيه؛ لا تعاد ترجمتها تلقائيًا بسبب عملة عقد العميل. لا توجد إعادة تقييم دورية لفروق صرف غير محققة أو دفتر أستاذ عام في هذه النسخة.
- الأتعاب النهائية = الأتعاب الأصلية + الأعمال الإضافية + الزيادات − الخصومات. دفعات المصمم لا تُضاف إلى التكلفة مرة ثانية.

## التحقق

اجتاز الإصدار 382 اختبارًا وتحققًا: 103 وحدات للحسابات والصور ودورة الحذف والاستعادة ودليل العملاء، و30 لتحديث السعر والترقيم والعرض، و32 لتدفقات العملاء في المتصفح، و26 لملاحظات V17 بأحدث نسخة مستخدم، و24 للربط واستعادة الصور، و29 لملاحظات V15، و42 لنقل النسخة الأصلية ووظائفها، و15 للحفظ والاستيراد، و25 للمستندات، و56 للعرض والطباعة. فُتحت ملفات XLSX الناتجة باستخدام openpyxl وفُحصت الأرقام وأسماء الأوراق والأنواع؛ لم يُشغّل Microsoft Excel في بيئة الاختبار. اكتمال الطلب الحالي يخص زر السعر والترقيم والعرض فقط، ولا يشمل الضريبة أو المزامنة ولا يعني ضمانًا عامًا ضد جميع الأخطاء.

```bash
python build.py
node --test tests/core.test.js tests/r15-core.test.js tests/linking-core.test.js tests/lifecycle.test.js tests/customers.test.js tests/presentation.test.js
python tests/presentation_browser.py
python tests/customers_browser.py --backup /path/to/latest.json
python tests/review_v15.py
python tests/review_v17.py --backup /path/to/latest.json
python tests/linking_browser.py --backup /path/to/latest.json --media-zip /path/to/original.zip
python tests/claim_print.py
python tests/attachments.py
python -m http.server 8004 --bind 127.0.0.1 --directory dist
```

ثم شغّل اختبارات `tests/reliability.py` و`tests/browser.py --zip /path/to/original.zip --original-dir /path/to/extracted/ronix_app`. يمكن تحديد `RONIX_TEST_URL` لاستخدام منفذ آخر. المتطلبات: Python Playwright وPyMuPDF وopenpyxl وChromium وNode. الصور والنسخ التجريبية الخاصة محفوظة في `private-test-artifacts` المتجاهل من Git.

البرنامج مستقل ويعمل دون تحميل مكتبات من الإنترنت. الاتصال الاختياري بمصدر سعر الصرف يحصل عند الضغط على زر التحديث فقط. مصدر V13 المنقح محفوظ في `src/v13-base.html`، وقواعد الحساب الأساسية في `finance-core.js` والربط والأرصدة الموحدة في `accounting-links.js`، واستعادة الصور في `media-core.js` و`media-recovery.js`، وإضافات هذه المراجعة في `r15-projects.js` و`r15-payments.js` و`r15-integration.js`. التصدير الحقيقي إلى XLSX في `xlsx-export.js` باستخدام fflate المضمنة بترخيصها. دليل العملاء في `customer-core.js` وواجهته في `r18-customers.js`. هذا التنظيم يفصل الحسابات عن العرض ويساعد على نقلها لاحقًا إلى تطبيق.

الاختبار تم عبر HTTP محلي في Chromium؛ لا يشمل كل أنظمة Windows أو المتصفحات. التخزين لا يزال محليًا في المتصفح، بلا مزامنة أو نسخ خارج الجهاز تلقائيًا. احتفظ بنسخة JSON تشمل الصور والمرفقات بعد العمل.

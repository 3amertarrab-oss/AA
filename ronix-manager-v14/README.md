# RONIX V14.1

تحديث مبني على برنامج RONIX V13 الأصلي، مع الحفاظ على المشاريع والمصممين والدفعات والتحصيل والمطالبات ومراكز التكلفة والصور والتقارير.

**[تنزيل النسخة الجاهزة V14.1](https://github.com/3amertarrab-oss/AA/raw/refs/heads/ronix-finance-download/ronix-manager-v14/RONIX-V14.1.zip)**

تحديث 24 أكتوبر 2026: قالب المطالبة أصبح A4 عموديًا بترويسة RONIX وجدول المشاريع والإجمالي والدفعات السابقة والتوقيعات، وفق الشكل الذي اختاره المستخدم. أزيل تكرار الجداول من المطبوعة، وتظهر خلاصة السداد الجزئي عند وجوده. المطالبات القصيرة تختصر في صفحة واحدة، والطويلة تستمر على صفحات إضافية مع تكرار رأس الجدول.

**[معاينة PDF ببيانات تجريبية](https://github.com/3amertarrab-oss/AA/raw/refs/heads/ronix-finance-download/ronix-manager-v14/preview/claim-preview.pdf)**

إذا تعمل حاليًا على V14، صدّر منه أحدث نسخة JSON ثم استوردها في التحديث، حتى تنتقل الحركات التي أدخلتها مؤخرًا.

افتح `RONIX_Manager.html` بعد فك الضغط، ثم اضغط **استيراد برنامجك القديم ZIP / JSON** واختر ZIP الأصلي أو أحدث نسخة احتياطية لديك. يعرض البرنامج عدد السجلات قبل الاستيراد. استيراد ZIP يضم الصور الموجودة معه إلى البيانات المحلية.

التحديث المنشور لا يحتوي على بيانات عملاء أو صور أو نسخ احتياطية خاصة. لا يتصل بخادم ولا يزامن البيانات بين الأجهزة. نزّل JSON احتياطيًا بعد جلسة العمل.

راجع [المواصفات والمراجعة الكاملة](المواصفات-والمراجعة.md) لصيغة التطوير المعتمدة، وقائمة الوظائف، وقواعد الحساب، والإصلاحات، وما بقي للتطوير.

## أبرز التغييرات

- تصحيح حصة المشروع في المطالبة المجمعة، وفصل القبض المخصص عن غير الموزع.
- مطابقة التحصيل بالمطالبة، والسداد الجزئي، ومنع استخدام نفس المبلغ مرتين.
- دعم القروش، مع إبقاء دقة القيم القديمة محفوظة وتوضيح تقريب التسويات.
- المحافظة على مرفقات النسخة الاحتياطية وروابط المشاريع عند التعديل.
- منع نجاح الحفظ الوهمي والتراجع عند امتلاء التخزين، وحماية التعديل من نافذة قديمة.
- استيراد ZIP محليًا، وتوسعة التقارير، وإضافة اسم المستفيد للمصروف.

## البناء والتحقق

الملف الجاهز في `dist/RONIX_Manager.html` مستقل. مصدر الشاشات الأصلية المنقح من البيانات الخاصة في `src/v13-base.html`؛ تحسينات الحساب والحفظ والاستيراد في ملفات منفصلة داخل `src`. مكتبة fflate 0.8.2 مضمّنة مع ترخيص MIT.

```bash
python build.py
node --test tests/core.test.js
python -m http.server 8004 --bind 127.0.0.1 --directory dist
```

في نافذة أخرى، بعد تثبيت Python Playwright وتوفير Chromium:

```bash
python tests/reliability.py
python tests/browser.py --zip /path/to/original-v13.zip --original-dir /path/to/extracted/ronix_app
```

اختبار النقل يستخدم النسخة الأصلية الخاصة التي يحددها المستخدم؛ بياناتها ليست جزءًا من المستودع. تُحفظ الصور ونسخة اختبار الاستعادة في مجلد متجاهل `private-test-artifacts`.

نجح 24 اختبار وحدات، و42 تحققًا في المتصفح باستخدام النسخة الأصلية، و15 تحققًا إضافيًا للحفظ والاستيراد والمرفقات والتعارض. نتائج المتصفح في `tests/*-results.json`.

لتحديث V14.1 نجح 19 تحققًا مخصصًا للطباعة: قياس صفحات PDF وكونها A4 عمودية، مطالبة قصيرة مع الصور والقبض الجزئي في صفحة واحدة، وعدم سقوط أي صف من مطالبة طويلة ذات 45 مشروعًا، والمحافظة على المبالغ والبيانات عند الطباعة. يمكن تشغيلها باستخدام Python Playwright وPyMuPDF وChromium:

```bash
python tests/claim_print.py
```

الاختبار عبر HTTP محلي في Chromium؛ لا يشمل اعتماد ملفات التصدير داخل تطبيق Microsoft Excel أو كل إصدارات Windows. لا يزال التشغيل محليًا بمتصفح واحد، وتبقى قاعدة مركزية والصلاحيات والنسخ التلقائية ودفتر الأستاذ وحسابات الموردين الكاملة ضمن التطوير اللاحق.

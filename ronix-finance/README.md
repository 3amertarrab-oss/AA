# RONIX Finance — نسخة الحسابات للتجربة

واجهة عربية لمتابعة المطالبات والتحصيلات والدفعات حسب المشروع والجهة، بالجنيه المصري افتراضيًا.

**[تنزيل نسخة التشغيل ZIP](https://github.com/3amertarrab-oss/AA/raw/refs/heads/ronix-finance-download/ronix-finance/RONIX-Finance-Easy.zip)**

1. نزّل الملف ثم اختر **استخراج الكل / Extract All** على الكمبيوتر.
2. افتح `RONIX-Finance.html` باستخدام Chrome أو Edge.
3. اضغط **تجربة ببيانات مثال**. ثم أزل مشروع المثال قبل إدخال بياناتك.

لا يحتاج ملف التشغيل إلى Python أو تثبيت حزم أو اتصال بالإنترنت.

البيانات تحفظ محليًا داخل المتصفح. استخدم **تنزيل نسخة احتياطية** بعد العمل، وعند الانتقال إلى جهاز أو متصفح آخر.

هذه نسخة تجريبية. اجتاز محرك الحسابات 25 اختبارًا، واختُبرت الواجهة والحفظ والاستيراد والتصدير على الهاتف والحاسوب عبر خادم محلي. طابق أول كشف مع حساباتك المرجعية قبل الاعتماد الفعلي. لا تحسب الضرائب والاستقطاعات تلقائيًا؛ أدخل القيمة النهائية للمطالبة.

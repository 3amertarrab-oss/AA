تجهيز RONIX للمزامنة

خطوات تُنفذ مرة واحدة. هذه الصفحة تولّد ملف إعداد مشروعك؛ لا تطلب كلمة مرور قاعدة البيانات أو مفتاحًا سريًا.

1. إنشاء حسابي الدخول

افتح Authentication ثم Users. أبقِ حساب المدير الحالي، وأنشئ حساب المحاسب عبر Add user → Create new user مع Auto Confirm User.

فتح مستخدمي المشروع

لا تضع كلمة المرور داخل SQL. أنشئها من شاشة Authentication واحتفظ بها خارج ملف البرنامج.

2. ربط المدير والمحاسب بنفس البيانات

بعد إنشاء المستخدمين، افتح SQL Editor والصق الكود ثم Run. إعادة تشغيله لا تحذف البيانات الموجودة.

فتح SQL Editor
عرض الكود أو نسخه يدويًا

3. نشر البرنامج وفتح الحساب

ارفع محتويات حزمة RONIX Cloud إلى Cloudflare Pages باستخدام Direct Upload. ملف index.html يجب أن يكون في جذر الرفع. سيعطيك رابطًا آمنًا للبرنامج. سجّل الدخول من الرابط ثم استورد أحدث JSON من التقارير مرة واحدة، وانتظر ظهور «تمت المزامنة».

فتح الملفات مباشرة من الكمبيوتر يصلح لقراءة هذه التعليمات. التطبيق والمزامنة يحتاجان رابط HTTPS أو خادم اختبار محلي.

4. الآيفون

افتح رابط البرنامج في Safari، سجّل الدخول بالحساب نفسه، ثم مشاركة ← إضافة إلى الشاشة الرئيسية. لا تستورد نسخة قديمة على الهاتف؛ ستظهر بياناتك المشتركة بعد الدخول.
